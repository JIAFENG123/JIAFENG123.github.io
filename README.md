# Jia Feng — 极简个人主页

专为开发者 **Jia Feng** 量身定制的东方极简（Swiss Minimalist × 文人写意白描）个人主页。

### 核心亮点
1. **纯粹极简，不落俗套**：去除所有花里胡哨的 3D、炫光、彩虹渐变和徽章墙，以高质量字阶排版、克制留白与黑白灰层次构建高级质感。
2. **东方工笔白描竹林（贝塞尔丝滑拔节生长）**：
   - **初始状态绝对空白**：首屏前 400ms 完全纯净空白，随后由地表第一像素开始，以三次贝塞尔缓动寸寸破土拔节，绝不闪现成品；
   - **左右双景、高低错落**：
     - **右侧主景**：高峻挺拔的擎天主竿（高约 83%）与伴生次竿、初生矮竹；
     - **左侧客景**：清秀倚竹（高约 53%）与玲珑幼竹；
   - **工笔大师级竹叶美学**：严格还原传统“个”字、“介”字叶簇结构，叶身饱满圆润、叶尖如剑锋锐利微垂，内置细微叶脉脊线；
   - **从容舒缓生长（约 6.5 秒）**：节节拔高、横生节环、抽枝、舒展竹叶，随风轻拂。
3. **灵动双雀（长尾仙禽 vs 短尾山雀）与物理阻尼动力学**：
   - **长尾仙雀（绶带风格）**：身形纤秀清雅，双羽展开优雅从容，拥有标志性的双缕飘逸长尾羽（长达 32px），停驻时长翎顺枝倾泻垂落，随风与呼吸轻扬起伏；
   - **短尾灵雀（小山雀风格）**：身形小巧圆润、胸腹饱满，喙部短促精干，配以灵动机敏的短翘燕尾羽，振翅轻快凌厉，停歇时短尾微翘 15° 显俏皮好奇；
   - **【彻底杜绝飞落后立即反向】**：
     - 落地瞬间严格保持飞行惯性航向（`flightFacing`），绝不瞬间镜像调头；
     - 驻足期间主要通过灵巧的头部张望（`headTurn`）和眼神交流展现自然顾盼；
     - 驻足中后期若需顾盼身后同伴，小鸟执行极微小的枝头轻跃换向（Hop-turn），带有物理回弹缓冲；
   - **【三段式无顿挫平滑进近与物理屈膝缓冲】**：
     - **巡航阶段（0% ~ 72%）**：严格单调贝塞尔曲线从容滑行，绝无局部折返；
     - **进近滑翔（72% ~ 100%）**：小鸟由扑翼自然切换为展翅滑翔姿态，双翼渐进收拢，双爪提前前伸迎枝，身体仰角平滑拉平（Flare）；
     - **触枝缓冲（Touchdown）**：引入真实物理阻尼弹簧（Spring-Damper Shock Absorption），落地瞬间初始形变为 0，平滑下蹲卸力再轻柔回弹，彻底杜绝了帧间坐标跳跃与卡顿顿挫感；
   - **【重力受弯与枝条弹性联动】**：
     - 触枝时竹枝受重下弯约 13px，小鸟双爪牢牢扣住枝条随风摇曳，浑然一体；起飞时竹枝卸重欢快反弹，符合真实工笔写意神韵。
